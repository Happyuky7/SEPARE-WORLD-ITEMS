# SepareWorldItems v2 — Original (pre-expansion)

This is the original Bukkit/Spigot/Paper/Folia plugin written by Happyuky7, exactly as it was before the
v3 multi-platform expansion (including the pending 26.x work that was staged at that time).

It is kept as the working reference implementation and is **not** part of the Gradle build.
It still builds on its own with Maven:

```bash
cd Code/SepareWorldItems-Original
mvn clean package
```

The v3 plugin (Gradle, shared `api`/`common`, Fabric/Forge/Hytale siblings) lives in `Code/bukkit/`.
